# Jago Hitung 🧮

Website latihan matematika harian bergaya game untuk anak SD, persiapan Olimpiade (OSN SD).

## Cara membuka
Klik dua kali `index.html` (buka di Chrome/Safari/Edge). Tidak perlu internet, kecuali untuk memuat font.
Untuk tablet/HP: unggah folder ini ke hosting statis (mis. GitHub Pages / Netlify), lalu buka alamatnya.

## Isi materi (mengikuti Silabus OSN SD)
| Bagian | Topik |
|---|---|
| 1. Aritmatika | Penjumlahan, Pengurangan, Perkalian, Pembagian, Kotak Misteri, Operasi Campuran, Soal Cerita, Hitung Cerdas |
| 2. Bilangan | Nilai Tempat, Ganjil & Genap, Pola Bilangan, Pecahan, Faktor & Kelipatan, Bilangan Prima, KPK & FPB |
| 3. Geometri | Bangun Datar, Keliling, Luas, Sudut, Simetri, Bangun Ruang |
| 4. Data & Pengukuran | Waktu & Jam, Satuan Ukuran, Membaca Diagram, Modus/Rata-rata/Median |
| 5. Logika & Kombinatorik | Pola Gambar, Banyak Cara, Teka-teki Logika |

Setiap topik punya 3 level (2 pelajaran per level, 8 soal per pelajaran). Soal dibuat acak, jadi selalu baru.
Di akhir setiap bagian ada **Ujian Bagian** 🏆.

## Fitur game
- Jalur belajar, mahkota 👑 per level, hati ❤️, combo 🔥, XP ⚡, permata 💎
- Runtunan harian & target harian, Latihan Kilat 60 detik
- Toko topi untuk maskot Momo, Pembeku Api, lencana prestasi
- Pengaturan orang tua (Profil): nama, target harian, suara, buka semua topik, reset

Progres tersimpan di browser perangkat (localStorage).
